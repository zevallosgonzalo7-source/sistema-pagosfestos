# FESTOS V29.40.1 — Motion Premium + Dark Mode Global + Wordmark

## Cambios principales
- Se reemplazó el branding basado en PNG por una marca tipográfica premium en login, sidebar, topbar y bienvenida.
- Se mantiene exactamente el texto: FESTOS GESTIÓN EMPRESARIAL / OPERACIONES Y ADMINISTRACIÓN.
- Se agregó una capa global de microanimaciones: cards, módulos, accesos, botones, iconos, filas, inputs y transiciones de vista.
- Fondo claro con gradientes ambientales animados muy sutiles.
- Modo oscuro rehecho de forma global para mejorar contraste y coherencia en Inicio, Cotizaciones, Compras, Proyectos, Caja, Planilla, calendarios, tablas, filtros, modales, dropdowns y permisos.
- Se respeta `prefers-reduced-motion` para accesibilidad.

## Nota
No se modificó lógica de negocio ni Supabase. Es una revisión visual sobre la V29.40 entregada por el usuario.

## Validación local
En esta sesión `npm ci` excedió el tiempo disponible, por lo que no se pudo ejecutar el build completo aquí. Ejecutar localmente:
