# FESTOS V27.3 · Iconografía lineal corporativa

Cambios visuales:

- Se retiraron los emojis de la interfaz React.
- Nuevo sistema interno de iconos SVG lineales, inspirado en el lenguaje visual de Lucide.
- Sidebar con iconos consistentes para Inicio, Dashboard, Clientes, Proveedores, Proyectos, Cotizaciones y Roles.
- Acciones de editar, eliminar, ver detalle, activar/desactivar, descargar, exportar, búsqueda, notificaciones y perfil usan iconografía SVG.
- Dashboard General, Inicio, Perfil, Roles y módulos ocultos también quedaron preparados sin emojis.
- No se modificaron tablas, datos ni reglas de negocio de Supabase.
- Se conservan los fixes visuales de V27.2.

Versión de aplicación: 1.1.3
