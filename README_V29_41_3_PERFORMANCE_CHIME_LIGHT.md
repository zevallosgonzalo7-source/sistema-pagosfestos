# FESTOS V29.41.3 — Performance + Chime Boost + Light Only

## Cambios
- Se retiró el modo oscuro y su botón de la interfaz.
- FESTOS queda oficialmente en tema claro premium.
- Chime de entrada con volumen aumentado (~2.4x a nivel master gain).
- Fondo reactivo al cursor optimizado con requestAnimationFrame.
- Menos repaints/reflows al mover el mouse.
- Blurs ambientales reducidos internamente, manteniendo la apariencia visual.
- Animaciones continuas ya no animan filtros pesados cuando no es necesario.
- En pantallas pequeñas se reduce una capa blur secundaria para mejorar fluidez.
- Se mantienen intro, teléfono, logo, glow, fondo animado, hover y microanimaciones.

## Nota
No requiere SQL.
