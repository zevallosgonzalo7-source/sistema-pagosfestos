# FESTOS V29.41.8 — Cotizaciones: ítems, adjuntos y superficies blancas

## Cambios
- En el detalle de cada ítem, el bloque numerado fue reemplazado por la cantidad.
- Debajo del nombre del ítem se muestra la utilidad total del ítem.
- El orden de métricas queda: Costo → Valor venta → Margen.
- El bloque de Proforma aprobada / Adjuntos se puede colapsar y expandir con una flecha.
- Proforma aprobada y adjuntos pueden eliminarse con confirmación cuando el usuario puede gestionar cotizaciones.
- Las superficies gris/verde del detalle de ítems y del bloque de adjuntos ahora son blancas, con bordes y sombras suaves.

## Límites existentes
- Proforma aprobada: máximo 1 archivo por cotización.
- Adjuntos complementarios: máximo 5 archivos por cotización.
