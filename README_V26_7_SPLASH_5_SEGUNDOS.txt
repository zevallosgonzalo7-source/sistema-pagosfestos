FESTOS V26.7 · PANTALLA DE INICIO DE 5 SEGUNDOS

Cambio puntual: la animación inicial se mantiene a la vista durante aproximadamente cinco segundos antes de mostrar la pantalla de inicio de sesión o la ventana principal. Si la aplicación tarda más de cinco segundos en cargar, la animación sigue visible hasta que esté lista.

Los demás módulos, datos, Supabase y diseño no cambian. Este ZIP contiene el proyecto, no el instalador .exe.

INSTALADOR WINDOWS
1. Extraer en una carpeta nueva FUERA de OneDrive; abrir la carpeta que contiene package.json.
2. Abrir PowerShell allí y ejecutar: npm install
3. Al terminar sin errores ejecutar: npm run desktop:build
4. En la carpeta release buscar FESTOS-Gestion-Empresarial-Setup-1.0.2.exe
5. Probar el instalador en el propio PC antes de compartirlo.

No es necesario ejecutar SQL ni modificar la base de datos.
