# FESTOS V29.20 · Dashboard sin huecos

Se reorganizaron los paneles de ejecutivos, proyectos, categorías y clientes en dos columnas independientes: los proyectos siguen inmediatamente al panel de ejecutivos, sin reservar la altura de la tarjeta de categorías. Cada tarjeta mantiene altura intrínseca; a menos de 1100 px las columnas pasan a una sola. Se conservaron los filtros, los gráficos, la navegación y las consultas de Supabase. No requiere SQL.
