## Filtros Premium Globales
Se homogeneizó visualmente el sistema de filtros de:
- Dashboard
- Clientes
- Proveedores
- Proyectos
- Cotizaciones
- Registro de Compras
- Calendario Global

Los filtros toman como referencia visual el Dashboard de Proyectos:
- fondo blanco/gris muy suave
- borde fino verde petróleo
- alturas uniformes
- radios consistentes
- focus elegante
- dropdowns opacos y por encima del contenido
- espaciado/responsive uniforme
