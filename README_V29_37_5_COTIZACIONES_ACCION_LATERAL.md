# FESTOS V29.37.5 — Cotizaciones acción lateral

- Cotizaciones vuelve a comportarse como un módulo normal: al pulsar la tarjeta abre directamente el listado.
- Se elimina el desplegable inferior con “Ver cotizaciones / Nueva cotización”.
- Al pasar el cursor o enfocar la tarjeta aparece un único emergente lateral: “Nueva cotización”.
- En móvil el acceso rápido a nueva cotización queda como botón compacto con + dentro de la tarjeta.
- No requiere cambios SQL.
