# FESTOS V29.42.2 — Dashboard de Registro de Ventas compacto

- Se eliminó la duplicidad visual entre tarjetas de alertas y KPIs.
- KPIs principales: Facturado, Cobrado, Por cobrar y Detracción pendiente.
- Las alertas pasan a una franja compacta y clickeable: vencidas, vencen en 7 días y detracciones pendientes.
- La franja de alertas desaparece automáticamente cuando no existe ninguna alerta.
- Se eliminó la alerta "Cobradas" porque ya está representada por el KPI "Cobrado".
- No requiere SQL nuevo.
