# FESTOS V29.34.9 — Registro de Compras

Cambios:
- En las tarjetas/listado de compras, el importe vuelve a llamarse **Valor compra** y muestra el valor base de la compra.
- **Precio de compra** se mantiene únicamente dentro de **Ver detalle**, tal como se solicitó.
- El cuadro rojo **Compras sin adjunto** ahora es clickeable.
- Al hacer clic, el listado muestra únicamente compras que no tienen PDF, XML ni COTIZACIÓN.
- Al activar el filtro, la vista baja suavemente al listado.
- Un segundo clic sobre el cuadro rojo desactiva el filtro.
- **Limpiar filtros** también elimina el filtro de compras sin adjunto.
- No requiere SQL adicional respecto a V29.34.8.
