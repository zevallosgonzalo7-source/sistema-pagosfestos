# FESTOS V29.31

## Cambios principales
- Se retira la vista Inicio. Después de iniciar sesión se abre directamente Dashboard proyectos.
- El Dashboard incorpora una bienvenida compacta y contextual.
- Centro de trabajo pasa a ser Calendario global colaborativo.
- El calendario permite actividades, entregas, reuniones, recordatorios y notas con color, responsable, proyecto, fecha/hora y notas.
- El calendario usa Supabase Realtime para sincronizar al equipo.
- Dashboard Ventas permanece oculto.
- Se actualiza el Manual de Usuario a V31 y se consolida la información en un solo PDF.
- El launcher mantiene Cotizaciones, Proyectos y Clientes como accesos obligatorios superiores y conserva favoritos para los demás.

## Instalación
1. Ejecutar supabase/FESTOS_V29_31_CALENDARIO_GLOBAL.sql.
2. Desplegar el código de esta versión.
