# FESTOS V29.37.6

Cambios incluidos:

1. Cotizaciones
- Nueva cotización y Editar cotización ahora se muestran como panel lateral/drawer.
- Mismo patrón visual del modal lateral usado por Proyectos.
- Mantiene toda la lógica de cliente, proyecto, ítems, márgenes y acciones.
- En móvil el drawer ocupa casi toda la pantalla desde abajo.

2. Dashboard Compras
- Se eliminó el gran espacio vacío entre las tarjetas de análisis y la evolución mensual.
- Las tarjetas ahora fluyen en dos columnas independientes:
  - Izquierda: CeCo, LOB, Evolución mensual.
  - Derecha: Categoría de gasto, Top proveedores, Últimas compras.
- En pantallas pequeñas se apilan en una sola columna.

No requiere SQL.
