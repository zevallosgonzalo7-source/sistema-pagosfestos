# FESTOS V29.34.5 - Catálogos de Registro de Compras

- LOB, CeCo y Categoría de gasto ahora se cargan desde Supabase.
- Categoría y Categoría de gasto son campos distintos.
- Categoría conserva el catálogo comercial de FESTOS.
- Categoría de gasto usa el catálogo administrativo definido por gerencia.
- Se agregaron filtros buscables para CeCo y Categoría de gasto.
- No se altera la lógica de comprobantes, adjuntos, fecha de control ni número de documento.

Ejecutar `supabase/FESTOS_V29_34_5_CATALOGOS_COMPRAS.sql` una vez antes de usar esta versión.
