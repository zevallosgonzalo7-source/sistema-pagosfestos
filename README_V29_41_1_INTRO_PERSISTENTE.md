# FESTOS V29.41.1 — Intro persistente premium

## Cambios
- La pantalla de bienvenida ya no se cierra automáticamente.
- Permanece visible hasta que el usuario haga clic.
- El teléfono continúa flotando y rotando suavemente mientras la pantalla está abierta.
- El wordmark FESTOS mantiene microanimación continua.
- El icono de FESTOS proporcionado se integró como elemento flotante junto al teléfono.
- Se agregó un startup chime muy corto usando Web Audio API, sin depender de archivos externos.
- El sonido funciona a nivel navegador tanto en Windows como macOS cuando las políticas de autoplay permiten audio tras el login.
- Se mantiene soporte para modo oscuro y prefers-reduced-motion.
