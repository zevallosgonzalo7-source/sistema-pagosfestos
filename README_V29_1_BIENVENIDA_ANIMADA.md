# FESTOS V29.2 · Bienvenida animada

Se agrega una bienvenida corporativa posterior a la autenticación segura.

- Saludo dinámico según la hora.
- Nombre del usuario autenticado.
- Cargo obtenido del perfil de Supabase.
- Correo corporativo.
- Foto de perfil local, si existe.
- Animación verde petróleo con glow, órbitas, barrido y progreso.
- Duración aproximada: 5 segundos.
- Se muestra una sola vez por sesión y también al abrir la app con una sesión ya vigente.
- Puede cerrarse antes haciendo clic fuera de la tarjeta.
- Respeta `prefers-reduced-motion`.

No cambia tablas, RLS ni datos de negocio.
