# FESTOS V29.37.4 — Cotizaciones con desplegable

## Cambios
- El módulo `Cotizaciones` del launcher ahora se comporta igual que `Dashboard` y `Caja`.
- Al pulsar Cotizaciones se abre un desplegable con:
  - `Ver cotizaciones`
  - `Nueva cotización`
- `Ver cotizaciones` abre el listado normal.
- `Nueva cotización` abre directamente el formulario de creación usando el flujo ya existente de FESTOS.
- Se conserva el estado activo del módulo y el diseño premium existente del submenú.

## Incluye también los cambios acumulados de V29.37.3
- Dashboard Proyectos con panel ejecutivo estilo Dashboard Compras.
- Corrección del gran espacio vacío en Dashboard Compras.
- Exportar Excel en Dashboard Compras con el mismo formato premium usado por Dashboard Proyectos.

No requiere SQL.
