# FESTOS V26.2 — Legibilidad + Treemap de Ejecutivos

Cambios aplicados sobre V26.1:

- Se amplió la legibilidad general de la aplicación en navegación, formularios, listados, tarjetas y detalles de cotización.
- El Dashboard general aprovecha hasta 1480 px de ancho en pantallas grandes.
- Se aumentó la tipografía del Dashboard proyectos: filtros, KPIs, títulos, leyendas, tablas y textos auxiliares.
- Los importes superiores ya no usan puntos suspensivos: se muestran completos.
- Los KPIs cambian automáticamente a 3 columnas cuando el ancho disponible no permite leer los importes cómodamente.
- "Valor por ejecutivo" fue reemplazado por un treemap de "Participación por ejecutivo".
- En el treemap, el área de cada ejecutivo representa su participación en el valor total de proyectos; el líder se resalta en verde petróleo.
- El Dashboard ventas permanece únicamente diseñado y sin vinculación de datos.

Fuentes del Dashboard proyectos: cotizaciones, proyectos, clientes y proveedores.
