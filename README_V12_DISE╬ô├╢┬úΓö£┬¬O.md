# CSSFESTOS V12 · Diseño moderno

Cambios visuales y de perfil sobre V11, sin cambiar la lógica de Clientes, Proveedores, Proyectos, Cotizaciones ni pagos:

- Clientes / Proveedores / Cotizaciones: búsqueda en fila 1 y filtros en fila 2.
- Proyectos: subtotal filtrado en una tercera fila, subrayado con verde petróleo/teal.
- Microinteracciones hover en tarjetas, controles y botones.
- Perfil superior con menú de tres puntos.
- Nuevo apartado Mi perfil: foto, nombre visible y cambio de contraseña.
- Foto de perfil y nombre visible se guardan localmente para no modificar el esquema actual de usuarios.
- Contraseña se actualiza usando el RPC `cambiar_password` que ya existe en V15.
- Logo `festoslogo-Photoroom.png` integrado en sidebar y cabecera.
- Nombre general del sistema: `FESTOS Gestión Empresarial`.
